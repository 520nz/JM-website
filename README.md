# 🎵 林俊杰粉丝答题

为演唱会答准备的 JJ 粉丝专属答题练习网站。

## 🚀 在线访问

```
https://cdn.jsdelivr.net/gh/520nz/JM-website@main/index.html
```

国内用户推荐使用上方 jsDelivr CDN 链接，国内 CDN 节点加速，秒开。

## 📋 功能

- **随机练习**：快速(10题) / 标准(20题) / 强化(30题) 三种模式
- **分类练习**：按专辑、歌曲、个人信息、获奖记录分类答题
- **错题本**：自动收集错题，支持间隔重复复习
- **数据统计**：正确率趋势图、分类统计、成就徽章
- **每日打卡**：设定每日目标，连续打卡记录
- **题库管理**：支持新增/编辑/删除题目，导入导出数据
- **成绩分享**：答题完成后一键生成分享卡片和文案

## 🛠 技术栈

纯静态前端（HTML + CSS + Vanilla JS），数据存储在浏览器 localStorage。
